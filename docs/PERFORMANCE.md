# Performance methodology

BRACE measures synthetic, reproducible workloads rather than personal profiles. `npm run test:stress` creates its database in a temporary directory, exercises create, search, pin, update, two-connection WAL, backup, restart, and integrity behavior, emits JSON metrics, enforces recorded ceilings, and removes the profile.

Graph tests benchmark logical corpora through 10,000 nodes while the renderer uses bounded Overview, Focus, and All projections. Spatial buckets replace quadratic global collision passes. DOM and SVG work remain capped; the accessible list reflects the current projection.

Indexing runs in a worker and reports cancellation and progress without blocking Electron's main event loop. Website audits cover desktop, laptop, tablet, and mobile layouts, focus, axe, reduced motion, interactions, horizontal overflow, console errors, and long tasks.

CI logs are the current metric record. Performance numbers vary by runner and are treated as regression evidence, not marketing guarantees.
