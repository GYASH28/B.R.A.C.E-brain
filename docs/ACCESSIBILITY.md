# Accessibility conformance notes

BRACE targets WCAG 2.2 AA where applicable; this is an engineering target, not a third-party certification.

The desktop supports keyboard navigation, visible focus, named controls and states, reduced motion, responsive and zoomed layouts, non-color status labels, and modal focus handling. The Brain graph has search, filters, keyboard spatial movement, selection details, and an equivalent accessible node index. Fullscreen and focus mode have visible and keyboard exits.

The public website has skip links, semantic landmarks, focus-visible styles, reduced-motion behavior, an immediately available skip for the opening sequence, deterministic keyboard interactions, and automated axe, layout, and focus checks at multiple viewports.

Known gaps requiring continued manual testing include Windows high-contrast nuance, screen-reader testing across platform and browser combinations, and native packaged journeys on every assistive-technology stack.
