03

SOURCE

Add the smallest useful project boundary.

Choose a project repository or notes folder. Never select your home directory or an entire drive.

BRACE reads
Markdown, plain text, JSON, YAML, source code, and other allowlisted text.
BRACE ignores
Credentials, environment files, databases, logs, dependencies, build output, caches, and symlink targets.
BRACE stores
Private-path-free project URIs, hashes, headings, chunks, entities, and relationships.

Indexing is incremental. Removed source files leave the index, while durable memories remain until you forget or supersede them.

07

LOCAL CONTROL

Back up, export, forget, or delete.

These actions remain separate because recovery, portability, and deletion have different consequences.

Create SQLite backup
A consistent copy of the complete local database for recovery.
Export portable JSON
Memory, decisions, evidence, relationships, skill metadata, and settings without machine-specific roots.
Forget one memory
Removes its content, evidence, and vector. A non-sensitive tombstone preserves audit integrity.
Delete all local data
Requires typing DELETE. Imported originals remain untouched.

Windows%APPDATA%\BRACE\brace.sqlite3

Linux$XDG_DATA_HOME/brace/brace.sqlite3or ~/.local/share/brace/brace.sqlite3

OverrideBRACE_DATA_DIRUse a specific directory, never a drive root.

Backups are sensitive. Keep them in encrypted storage and never commit them to Git.

TROUBLESHOOTING

Find one safe next check.

Choose a symptom or search above.You will get a focused first check and the safest next action.
Why does Search say “lexical”?

That is the private default. Enable a working embedding adapter only when you want semantic or hybrid ranking.

Why is an imported file missing?

BRACE excludes hidden, credential-like, binary, oversized, database, dependency, build, cache, and symlink content.

Why can my AI search but not remember?

MCP is read-only by default. Enable write permission only after read-only recall works.

Can I use a cloud embedding endpoint?

The core adapter permits HTTPS endpoints, but doing so sends indexed text to that provider. The desktop first-run interface exposes local Ollama only.
