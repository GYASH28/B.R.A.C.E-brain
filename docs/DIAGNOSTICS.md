# Diagnostics and support bundles

Settings can run local diagnostics for application and platform version, database schema and quick-check status, aggregate counts, indexing jobs, embedding configuration state, connector health, watcher state, and automation scheduler state.

A support bundle is opt-in and previewed before saving. By default it excludes memory titles and content, source text, project names and paths, provider credentials, client configuration contents, and application logs. Errors are sanitized before inclusion. Nothing is uploaded automatically.

Raw SQLite backups and user-selected logs are not support bundles; treat them as sensitive user data.
