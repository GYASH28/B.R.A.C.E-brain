# Current limitations

- BRACE 0.7.0 is a preview. Windows artifacts are not Authenticode-signed and there is no automatic updater.
- The public website has strict performance budgets for first paint, largest paint, long tasks, transfer, request count, DOM size, layout shift, and browser errors. A release candidate must pass that audit on a clean, idle runner; shared-machine contention is not a reason to waive the budget.
- The local organization foundation provides workspaces, roles, member records, and audit events on one device. Schema v8 and the deny-by-default kernel enforce Electron workspace-member mutation plus dedicated shared publication, read, lexical-search, graph, export, and AI-context-preview seams. Schema v9 adds a signed Ed25519 assertion verifier and local sessions that recheck expiry and subject suspension/revocation before use; raw assertions are not stored and replay is rejected. No legacy identity, owner, or session is backfilled.
- Business role lenses are presentation-only. They do not grant access. The identity-session foundation has no default trusted issuer and no public enrollment UI, so the current product still does not claim cloud collaboration, complete OIDC/SAML SSO, SCIM, remote tenant administration, multi-device token revocation, or cryptographic multi-user authorization. Role changes and Publish to company intentionally remain locked in an unprovisioned build.
- Schema v10 provides a tested, transport-neutral encrypted company-sync operation log and local replica core for explicitly published records: AES-256-GCM envelopes, external key references, exact tenant/workspace/device authorization, replay handling, out-of-order conflicts, tombstones, leases, and local revocation. It is not a shipped network sync product. There is no remote tenant service, TLS protocol, managed/self-hosted deployment, object attachment path, production keystore integration, cross-tenant infrastructure qualification, or multi-device UI.
- Schema v11 adds only a local approval/audit foundation for future agents: immutable bounded plan hashes, expiring human decisions, one-time service consumption, a tamper-evident local audit chain, and verified workspace-scoped evidence export. It ships no company connector, agent enrollment, external write, remote audit/checkpoint service, organization-wide independently verifiable audit export, or execution-time budget/compensation runtime. See ADR-005 through ADR-007 for the required gates.
- The SQLite database is not application-encrypted. Use operating-system account protection and full-disk encryption.
- Secret scanning is best-effort and cannot certify imported content safe.
- Local scheduling runs while the desktop application is open. It is not an operating-system background daemon.
- Watch mode depends on operating-system filesystem notifications and may require a manual reindex after missed or unavailable events.
- Semantic and hybrid retrieval require real compatible embedding vectors. Otherwise the product labels results lexical.
- Import supports bounded Markdown, plain text, and BRACE JSON profile data. PDF, DOCX, OCR, audio, image, and browser-history ingestion are not included.
- macOS signed and notarized distribution is not qualified.
